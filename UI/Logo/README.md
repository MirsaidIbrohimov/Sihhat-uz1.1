# Sihhat.uz — Yangi T6 Aurora Logo Konsepsiyalari (`UI/Logo`)

## Ko‘rish

Brauzerda [index.html](index.html) faylini oching (internetsiz ishlaydi, `←` / `→` tugmalari hamda tungi/kunduzgi fon almashtirgichi bor) yoki umumiy taqqoslash jadvalini ko‘ring: [00-barcha-logolar-taqqoslash.png](00-barcha-logolar-taqqoslash.png).
