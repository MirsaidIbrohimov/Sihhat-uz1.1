# APK uchun motion dizayn takliflari

2026-11-06. `index.html` faylini brauzerda oching. Internet yoki server shart emas; CSS, JS, shrift, ikonka va konsept rasmi repozitoriyadagi lokal fayllardan olinadi. Papkani alohida ko‘chirish o‘rniga `UI` papkasini to‘liq saqlang.

- **Sokin premium:** iliq fon, tabiiy yashil, serif sarlavha, katta fotografiya.
- **Aurora:** chuqur tungi fon, yalpiz aksent, shaffof navigatsiya.
- **Fresh:** oq kartalar, ko‘k aksent, ixcham banner va aniq shakllar.

Uslublarni birga yoki alohida ko‘rish mumkin; alohida variant uchun `#calm`, `#aurora`, `#fresh`. Telefon ichidagi sahifalar aylanadi. Katalog qidiruvi, Tog‘/Bog‘ filtrlari, sevimlilar, tafsilot, sana/mehmon tanlash, jami hisob va namunaviy tasdiq ishlaydi. Sevimlilar sahifa sessiyasida saqlanadi. Motion tugmasi animatsiyani o‘chiradi; tizimning reduced-motion tanlovi ham hurmat qilinadi.

Harakatlar: kontentning ketma-ket paydo bo‘lishi, banner fotosining sekin yaqinlashuvi, tugmaning bosilish javobi, ekranlar o‘tishi va tasdiq belgisi. Harakatni takrorlash sahifani yangilaydi, tanlovlarni saqlaydi.

Barcha maskan nomlari, baholar, xizmatlar va narxlar namuna. Rasm mavjud `UI/web/assets/retreat.png` konsept assetidan olingan. Haqiqiy API, to‘lov, AI yoki bron xizmatiga ulanmaydi. Flutter ilovasi o‘zgartirilmagan.

Tekshiruv: JavaScript sintaksisi va lokal asset yo‘llari tekshirildi; `npm run check:secrets` bajarildi. Brauzer vizual/interaktiv tekshiruvi bajarilmadi: ko‘rish vositasi `file:` protokolini blokladi. Bu HTML taklif, APK yoki production qabul dalili emas.
